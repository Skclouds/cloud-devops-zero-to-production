# Scenario 04 Evidence

Preserve actual terminal output for:

- Initial source and target ownership and modes
- Deployment failure with Permission denied
- `namei -l` path inspection
- `test -r` and `test -w` exit codes
- Deployment user and group membership
- Updated target directory ownership and mode
- Successful deployment output
- Destination file `stat` output
- Source/destination `diff` verification

Do not add fabricated terminal output or credentials.
